One-Liner Marathon — a pure-stdlib Python program that writes one original one-line comedy joke to `entry.txt`:

> My AI agent never sleeps, never eats, and still asked HR for a mental health day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (deterministic — repeated runs are byte-identical). No dependencies beyond the Python standard library, no network at runtime.
